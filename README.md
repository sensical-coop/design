# Sensical Design Assets

This repository contains design assets for Sensical Coop (https://sensical.es). 

The logo folder contains different versions of the logo. Read the guidelines inside the logo folder for it's proper use.

## Color palette

- Sensical pink: #FF495F
- Black is pure black
- White is pure white
- Off-white (for accent) is #F8F9FA
